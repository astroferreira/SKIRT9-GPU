## Observation

```
/home/astroferrreira/SKIRT/benchmarks/z0_jwst_20260909
```

Configuration: `z0_355724_jwst_1k_10m.ski`; output: `run_1k_10m/`.

- Redshift 0, fiducial observer distance 10 Mpc. This is a synthetic full-field
  observation, not a single JWST pointing.
- Four views (xy, xz, yz, oct), each 150 kpc and 1000 x 1000 pixels.
- Eight NIRCam broadband filters and nine MIRI filters per view.
- 10 million primary and 10 million secondary packets, random seed 12345.
- Stochastic dust emission, 400-point radiation-field wavelength grid,
  1000-point dust-emission grid, high-resolution Bruzual-Charlot templates.
- Integrated 0.7-5.3 micron spectrum for each view, 4051 samples, rendered
  with an ideal constant-R=1000 Gaussian. This is not a calibrated NIRSpec LSF.
- NIRCam R/G/B = F444W/F277W/F115W; MIRI = F2100W/F1500W/F770W.
  Display stretch is asinh 30; the FITS data are not altered.

This is a first pass, not a demonstrated noise-converged observation. No
telescope PSF, detector noise, slit losses, or velocity broadening is applied.
Native stellar/MAPPINGS spectral-resolution limits remain.

    SKIRTGPU_PRECOMPUTE_SOURCE_SPECTRA=0 \
    SKIRTGPU_BATCH_FIRST_FORCED_CHUNK=2097152 \
    SKIRTGPU_VALIDATE_DUST_EMISSION=1 \
    /home/astroferrreira/SKIRT/release/SKIRT/main/skirtgpu -g -t 32 \
    -o /home/astroferrreira/SKIRT/benchmarks/z0_jwst_20260909/run_1k_10m \
    /home/astroferrreira/SKIRT/benchmarks/z0_jwst_20260909/z0_355724_jwst_1k_10m.ski

Both RTX 5090 devices are enabled. Full per-particle primary spectrum caching
is disabled to bound memory; this is a hybrid CPU/GPU observation. No CPU-only
comparison run was requested or launched. GPU stochastic dust emission is
enabled by default, with sampled scalar-reference validation enabled here.

The helper now gives both image and SED instruments a finite distance at z=0;

titles use an explicit galaxy label rather than a hardcoded z=1 galaxy ID.

precision scientific use; it was not suppressed to produce the images.
